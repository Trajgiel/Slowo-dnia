# Słowo dnia — польский на каждый день

**Słowo dnia** («Слово дня») — небольшое веб‑приложение, чтобы учить польский язык понемногу, по одному слову или фразе. Интерфейс на русском языке, приложение удобно открывать с телефона, планшета или компьютера.

🔗 **Открыть приложение:** https://trajgiel.github.io/Slowo-dnia/

## Курсы

| Курс | Слов | Тем | О чём |
|---|---|---|---|
| **Детский** | 500 | 71 | Школа, семья, игры, чувства, первые фразы — чтобы учить вместе с ребёнком |
| **Для взрослых** | 1000 | 100 | Жизнь в Польше: магазин, кафе, квартира, транспорт, банк, врач, urząd и документы, работа, общение |

При первом запуске приложение спрашивает, кто будет учиться. Курс можно сменить в любой момент в «Настройках» или нажав на название курса на главной. **У каждого курса свой прогресс**: выученные слова, слова для повторения, серия дней и результаты опроса.

## Что умеет

- **Слово дня.** Новое польское слово или короткая фраза с переводом на русский и транскрипцией русскими буквами (ударный слог отмечен). Подпись «Слово 37 из 1000» и тема слова.
- **Озвучка.** Кнопка «Послушать» произносит слово польским голосом через встроенный синтезатор речи браузера.
- **Отметка «Выучили».** Выученные слова отмечаются, приложение открывается на следующем невыученном слове. Темп любой: стрелкой → можно перейти к следующему слову сразу.
- **Прогресс и серия дней.** Статистика, полоса прогресса, точки по словам текущей темы и серия «🔥 N дней подряд». Когда выучена вся тема, приложение хвалит.
- **Опрос, режим «Колода».** Каждое выученное слово спрашивается один раз в случайном порядке. Видно, какая это карточка, сколько ответов правильных и сколько неправильных. В конце показывается итог: правильно, неправильно, всего, и кнопка «Решить заново». Для направлений «русский → польский» и «польский → русский» свои колоды и результаты, прошлый результат показывается под карточкой.
- **Опрос, режим «Без конца».** Выученные слова в случайном порядке и в обоих направлениях, без счёта. Слова, которые забылись («Не вспомнили»), попадаются чаще. Последний выбранный режим запоминается.
- **План.** Все слова курса по темам, у каждой темы счётчик выученного. Любое слово можно открыть из плана, темы можно проходить в любом порядке.
- **Подсказки «Как заниматься».** Советы для своего курса, памятка по польскому произношению (ł, ę/ą, sz/cz, ś/ć, rz/ż, y, ch) и полезные заметки.
- **Мужской или женский род.** В «Настройках» можно выбрать, кто учится, — «Девочка / Мальчик» в детском курсе и «Женщина / Мужчина» во взрослом, — и фразы от первого лица будут в нужном роде: «Skończyłam / Skończyłem» («Я закончила / закончил»), «Jestem zmęczona / zmęczony» («Я устала / устал»). По умолчанию — девочка и женщина, прогресс при переключении сохраняется.
- **Настройки.** Выбор курса, выбор рода, переключатель тёмной и светлой темы (по умолчанию тёмная), инструкция по установке на телефон, резервная копия прогресса обоих курсов, сброс прогресса текущего курса, контакты и информация об авторских правах.

## Как пользоваться

**Детский курс**
1. Утром откройте вкладку «Слово» — там уже новое слово.
2. Нажмите «Послушать» и повторите вместе 3–4 раза.
3. Вечером спросите: «Как по‑польски…?» Если ребёнок ответил — нажмите «Выучили».
4. Раз в неделю решайте колоду на вкладке «Опрос».

**Курс для взрослых**
1. Откройте вкладку «Слово», послушайте и повторите слово вслух.
2. Придумайте с ним свою фразу и скажите её в течение дня.
3. Запомнили — нажмите «Выучили» и переходите к следующему. Удобный темп — 3–5 слов в день.
4. Раз в неделю решайте колоду на вкладке «Опрос», а «Без конца» используйте для коротких повторений.

## Установка на телефон (PWA)

Słowo dnia — прогрессивное веб‑приложение (PWA): его можно установить на телефон или планшет. Появится иконка на главном экране, приложение будет открываться на весь экран без адресной строки и работать даже без интернета.

**iPhone и iPad**
1. Откройте https://trajgiel.github.io/Slowo-dnia/ в **Safari**.
2. Нажмите кнопку «Поделиться» (квадрат со стрелкой вверх).
3. Пролистайте вниз и выберите «На экран „Домой“».
4. Нажмите «Добавить».

**Android**
1. Откройте https://trajgiel.github.io/Slowo-dnia/ в **Chrome**.
2. Нажмите меню «⋮» в правом верхнем углу.
3. Выберите «Установить приложение» (или «Добавить на главный экран»).
4. Подтвердите, нажав «Установить».

Эта же инструкция есть в самом приложении, на вкладке «Настройки».

Если озвучка не работает, добавьте польский голос:
- **iPhone и iPad:** Настройки → Универсальный доступ → Устный контент → Голоса → Польский.
- **Android:** Настройки → Специальные возможности (или Система → Язык и ввод) → Синтез речи → ⚙ у «Синтезатора речи Google» → Установка голосовых данных → Polski.

## Где хранится прогресс

Прогресс (выученные слова, слова для повторения и серия дней) сохраняется в памяти браузера (`localStorage`) на каждом устройстве отдельно. Отметки, сделанные на телефоне, не появятся автоматически на компьютере. Если очистить данные сайта в браузере, прогресс сбросится. На iPhone установленное приложение хранит прогресс отдельно от Safari.

Чтобы не потерять прогресс или перенести его на другое устройство, используйте **«Настройки» → «Резервная копия прогресса»**: нажмите «Скопировать код» (или «Отправить…») и сохраните код, например, в Заметках. На другом устройстве вставьте код в поле и нажмите «Восстановить из кода». Там же есть кнопка «Сбросить прогресс».

## Устройство проекта

Сборки и зависимостей нет:

- [`index.html`](index.html) — всё приложение (HTML, CSS и JavaScript) и слова детского курса;
- [`courses/adult.js`](courses/adult.js) — слова курса для взрослых, загружаются только при выборе этого курса;
- [`manifest.webmanifest`](manifest.webmanifest) — описание PWA: название, иконки, цвета;
- [`sw.js`](sw.js) — service worker, сохраняет приложение в кэш для работы офлайн. После изменения иконок или шрифтов поднимите в нём `VERSION`, чтобы обновился кэш;
- [`icons/`](icons) — иконки приложения;
- [`fonts/`](fonts) — шрифты Nunito и Caveat (лицензия SIL OFL 1.1). Они лежат в репозитории, поэтому приложение не обращается к серверам Google и работает офлайн.

Чтобы запустить локально, достаточно открыть `index.html` в браузере (офлайн‑режим работает только по HTTPS, то есть на GitHub Pages).

Сайт публикуется через **GitHub Pages** из корня ветки `main`: после каждого `git push` изменения появляются по ссылке выше в течение минуты‑двух.
