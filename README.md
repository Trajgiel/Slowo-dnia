# Słowo dnia — польский на каждый день

**Słowo dnia** («Слово дня») — небольшое веб‑приложение для того, чтобы вместе с ребёнком учить польский язык понемногу, по одному слову или фразе в день. Интерфейс на русском языке, приложение удобно открывать с телефона, планшета или компьютера.

🔗 **Открыть приложение:** https://trajgiel.github.io/Slowo-dnia/

## Что умеет

- **Слово дня.** Каждый день — новое польское слово или короткая фраза с переводом на русский и транскрипцией русскими буквами (ударный слог отмечен).
- **Озвучка.** Кнопка «Послушать» произносит слово польским голосом через встроенный синтезатор речи браузера.
- **Отметка «Выучили».** Выученные слова отмечаются, а на следующий день приложение само открывается на следующем невыученном слове.
- **Прогресс и серия дней.** Статистика, полоса прогресса, точки по дням текущей недели и серия «🔥 N дней подряд». Когда выучена вся неделя, приложение хвалит ребёнка.
- **Опрос.** Повторение выученных слов в двух направлениях: русский → польский и польский → русский. Слова, которые забылись («Не вспомнили»), попадаются в опросе чаще.
- **Весь план.** 500 слов, разбитых по темам: 52 недели по 7 слов плюс 19 запасных недель (приветствия, вежливые слова, семья, числа, цвета, школа, еда, тёплые слова и многое другое). Любое слово можно открыть из плана.
- **Подсказки «Как заниматься».** Советы, как заниматься каждый день и повторять, памятка по польскому произношению (ł, ę/ą, sz/cz, ś/ć, rz/ż, y, ch) и полезные заметки.
- **Девочка или мальчик.** В «Настройках» можно выбрать, кто учится, и фразы от первого лица будут в нужном роде: «Skończyłam / Skończyłem» («Я закончила / закончил»), «Jestem uczennicą / uczniem» («Я ученица / ученик»), «Brawo, córeczko / synku!». По умолчанию — девочка, прогресс при переключении сохраняется.
- **Настройки.** Выбор «Девочка / Мальчик», переключатель тёмной и светлой темы (по умолчанию тёмная, выбор запоминается на устройстве), инструкция по установке на телефон, резервная копия прогресса, сброс прогресса и информация об авторских правах.

## Как пользоваться

1. Утром откройте вкладку «Слово» — там уже новое слово.
2. Нажмите «Послушать» и повторите вместе 3–4 раза.
3. Вечером спросите: «Как по‑польски…?» Если ребёнок ответил — нажмите «Выучили».
4. Раз в неделю устраивайте повторение на вкладке «Опрос».

## Установка на телефон (PWA)

Słowo dnia — прогрессивное веб‑приложение (PWA): его можно установить на телефон или планшет. Появится иконка на главном экране, приложение будет открываться на весь экран без адресной строки и работать даже без интернета.

**iPhone и iPad**
1. Откройте https://trajgiel.github.io/Slowo-dnia/ в **Safari**.
2. Нажмите кнопку «Поделиться» (квадрат со стрелкой вверх).
3. Пролистайте вниз и выберите «На экран „Домой“».
4. Нажмите «Добавить».

**Android**
1. Откройте https://trajgiel.github.io/Slowo-dnia/ в **Chrome**.
2. Нажмите меню «⋮» в правом верхнем углу.
3. Выберите «Установить приложение» (или «Добавить на главный экран»).
4. Подтвердите, нажав «Установить».

Эта же инструкция есть в самом приложении, на вкладке «Настройки».

Если озвучка не работает, добавьте польский голос:
- **iPhone и iPad:** Настройки → Универсальный доступ → Устный контент → Голоса → Польский.
- **Android:** Настройки → Специальные возможности (или Система → Язык и ввод) → Синтез речи → ⚙ у «Синтезатора речи Google» → Установка голосовых данных → Polski.

## Где хранится прогресс

Прогресс (выученные слова, слова для повторения и серия дней) сохраняется в памяти браузера (`localStorage`) на каждом устройстве отдельно. Отметки, сделанные на телефоне, не появятся автоматически на компьютере. Если очистить данные сайта в браузере, прогресс сбросится. На iPhone установленное приложение хранит прогресс отдельно от Safari.

Чтобы не потерять прогресс или перенести его на другое устройство, используйте **«Настройки» → «Резервная копия прогресса»**: нажмите «Скопировать код» (или «Отправить…») и сохраните код, например, в Заметках. На другом устройстве вставьте код в поле и нажмите «Восстановить из кода». Там же есть кнопка «Сбросить прогресс».

## Устройство проекта

Сборки и зависимостей нет:

- [`index.html`](index.html) — всё приложение (HTML, CSS и JavaScript);
- [`manifest.webmanifest`](manifest.webmanifest) — описание PWA: название, иконки, цвета;
- [`sw.js`](sw.js) — service worker, сохраняет приложение в кэш для работы офлайн. После изменения иконок или шрифтов поднимите в нём `VERSION`, чтобы обновился кэш;
- [`icons/`](icons) — иконки приложения;
- [`fonts/`](fonts) — шрифты Nunito и Caveat (лицензия SIL OFL 1.1). Они лежат в репозитории, поэтому приложение не обращается к серверам Google и работает офлайн.

Чтобы запустить локально, достаточно открыть `index.html` в браузере (офлайн‑режим работает только по HTTPS, то есть на GitHub Pages).

Сайт публикуется через **GitHub Pages** из корня ветки `main`: после каждого `git push` изменения появляются по ссылке выше в течение минуты‑двух.
